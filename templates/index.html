下载设置

下载
全局限速
KB/s
对多线程分段与流媒体下载同时生效，单位 KB/s。
下载线程数
新任务的默认分段数；越大越快但占用资源更多，单个任务还可以单独指定。
失败自动重试
任务失败后自动重试的次数；间隔 30秒/1分/2分/5分钟递增，会从分片残留处继续，0 = 关闭。
完成提示音
下载完成时播放声音；浏览器端用 WebAudio 复制桌面端的三声短音，桌面端仍由本机播放。
下载目录
与桌面端、浏览器捕获共用同一份配置，修改后对新任务生效。
下载代理
系统代理继承 HTTP_PROXY/HTTPS_PROXY；自定义需填完整地址，支持 http:// 与 socks5://。
全部下载完成后
仅在任务列表里再没有下载中 / 等待中 / 已暂停的任务后开始 60 秒倒计时；关闭程序不会自动取消，请用上面的按钮。设置会被记住，重启后仍然生效。
定时任务
无
界面与诊断
界面主题
默认跟随系统主题；浅色主题目前仅 Web 端提供。
浏览器捕获
接收浏览器扩展推送的下载/媒体链接，与桌面端“浏览器监控”共享同一份设置。
